# Scene Editor contract

## 0.1.1

Live settings use the shared paired bridge, prepared typography and isolated
persistent cache. Startup opens while the native supervisor connects; explicit
initial collisions forward only untouched selections. Settings and cache evidence
are available in app.describe. Legacy theme-file reload is retired.

## 0.1.0

Native Wayland application with shared application host, Ced-style menus,
Gallery, Installed Scenes and Panel Arrangement. Scene management stays in
the scene service. Adds `scene-editor.ping/info/show/action/quit`.
