# mix

The Mix language library: lexer, parser, evaluator, builtin contracts and
embedded handler interfaces. Features select the optional data, networking and
cryptographic facilities; the interpreter's core stays independent of the Bus
and desktop.

Transplanted from `cosmix-lib-mix` at cosmix
`e0297242305f3a3c3de09f1ca01e8faa771768da`, retaining its regression corpus and
public language version. The binary belongs to `cli/mix-shell`.
